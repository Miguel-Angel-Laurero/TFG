# Arranque local del proyecto

Para levantar el proyecto en local es necesario abrir dos terminales: una situada en la ruta del frontend y otra en la ruta del backend.

Antes de ejecutar el proyecto, debe instalarse Node.js en el equipo. Se recomienda usar la terminal de Git Bash para que los comandos se reconozcan correctamente.

En cada una de las terminales se debe ejecutar el siguiente comando:

```bash
npm run dev
```

Resumen de pasos:

1. Instalar Node.js.
2. Abrir una terminal de Git Bash en la carpeta del frontend.
3. Abrir otra terminal de Git Bash en la carpeta del backend.
4. Ejecutar `npm run dev` en ambas terminales.
